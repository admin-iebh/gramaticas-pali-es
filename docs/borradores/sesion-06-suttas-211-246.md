# BORRADOR — §211–§246, Catuttha Kaṇḍa (pendiente de aprobación de Angel)

*Sesión 06. Cuarta sección completa del Nāma-kappa. Traducido de Nandisena
(líneas 2215–2590), cotejado con Thitzana (líneas 10097–11496) y Pind
(líneas 2187–2499). Nandisena desglosa UN ejemplo por sutta; todos los demás
desgloses son expansión nuestra, comprobada por recomposición. Véanse las notas
de trabajo al final. Ojo a la numeración de Pind: sus §244–§245 (Obhāvo…,
Bhadantassa…) son suttas que Nandisena no cuenta, de modo que Nandisena
§244–§246 = Pind 246–248.*

**§211. 126. Attanto hismim anattaṃ (439).** [Atta-anto + hismiṃ + anattaṃ = 3 voces]

Tassa attano anto anattam āpajjate himhi vibhattimhi.
Attanehi, attanebhi.
Attanto ti kimatthaṃ? Rājehi, rājebhi.
Hismin iti kimatthaṃ? Attano.
Anattam iti bhāvaniddesena attasaddassa sakādeso hoti sabbāsu vibhattīsu. Sako, sakā, sakaṃ, sake.

---

Cuando sigue ‘hi’, [hay] ‘ana’ de la final de “atta”.

Cuando sigue la inflexión ‘hi’, la [vocal] final de “atta” se convierte en ‘ana’.

Ejemplos:

* Attanehi = atta + hi (‘a’ de “atta” se convierte en ‘ana’ (§211); ‘a’ se sustituye por ‘e’ (§101)).
* Attanebhi = atta + hi (‘a’ de “atta” se convierte en ‘ana’ (§211); ‘a’ se sustituye por ‘e’ (§101); ‘hi’ se sustituye por ‘bhi’ (§99)).

¿Cuál es la finalidad de decir “la final de ‘atta’”? [Este sutta no se aplica cuando no hay “atta”, como en:] rājehi, rājebhi.

¿Cuál es la finalidad de decir “cuando sigue ‘hi’”? [Este sutta no se aplica cuando no sigue ‘hi’, como en:] attano.¹

Por la expresión que indica estado “anattaṃ”, la palabra “atta” se sustituye por “saka” cuando siguen todas las inflexiones. Sako, sakā, sakaṃ, sake.²

Nota al pie: Attanā (Sī).

Nota al pie: Sakārādeso (K).

**§215. 141. Jha-lato ca (442).**¹ [Jha-lato + ca = 2 voces]

Jha la icc etehi smāvacanassa nā hoti.
Agginā, daṇḍinā, bhikkhunā, sayambhunā.
Smā ti kimatthaṃ? Aggayo, munayo, isayo.

---

Y tras ‘jha’ y ‘la’.

Tras ‘jha’ y ‘la’, la inflexión ‘smā’ deviene ‘nā’.

Ejemplos:

* Agginā = aggi + smā (‘i’ recibe el nombre ‘jha’ (§58); ‘smā’ se sustituye por ‘nā’ (§215)).
* Daṇḍinā = daṇḍī + smā (‘ī’ recibe el nombre ‘jha’ (§58); ‘ī’ se acorta (§84); ‘smā’ se sustituye por ‘nā’ (§215)).
* Bhikkhunā = bhikkhu + smā (‘u’ recibe el nombre ‘la’ (§58); ‘smā’ se sustituye por ‘nā’ (§215)).
* Sayambhunā = sayambhū + smā (‘ū’ recibe el nombre ‘la’ (§58); ‘ū’ se acorta (§84); ‘smā’ se sustituye por ‘nā’ (§215)).

¿Cuál es la finalidad de decir ‘smā’? [Este sutta no se aplica cuando no sigue ‘smā’, como en:] aggayo, munayo, isayo.

Nota al pie: Caggahaṇaṃ kvaci nivattanatthaṃ (Rū.), caggahaṇaṃ tadanukaḍḍhanatthaṃ (Nyā.) (El tomar “ca” es para excluir “kvaci” (Rū.); el tomar “ca” es para el arrastre de eso (Nyā.)).

**§217. 199. Yonaṃ ni napuṃsakehi (444).** [Yonaṃ + ni + napuṃsakehi = 3 voces]

Sabbesaṃ yonaṃ ni hoti vā napuṃsakehi liṅgehi.
Aṭṭhīni, aṭṭhī; āyūni, āyū.
Napuṃsakehī ti kimatthaṃ? Itthiyo.

---

Tras las bases neutras, [hay] ‘ni’ de ‘yo’.

Opcionalmente, tras las bases neutras, todos los ‘yo’ devienen ‘ni’.

Ejemplos:

* Aṭṭhīni = aṭṭhi + yo (‘yo’ se sustituye por ‘ni’ (§217); ‘i’ se alarga (§88)).

* Āyū = āyu + yo (‘yo’ se elide (§118); ‘u’ se alarga (§88)).

¿Cuál es la finalidad de decir “tras las [bases] neutras”? [Este sutta no se aplica cuando no hay bases neutras, como en:] itthiyo.

Nota del traductor: en el desglose Nandisena imprime “aṭṭhīṇi”, con ‘ṇ’ retrofleja; sus propios ejemplos, Pind y Thitzana leen “aṭṭhīni”, por lo que se propone la enmienda ‘ṇi’ → ‘ni’.

**§220. 74. Sesato lopaṃ ga si pi (447).** [Sesato + lopaṃ + gasi + api = 4 voces]

Tato niddiṭṭhehi liṅgehi sesato ga si icc ete lopam āpajjante.
Bhoti itthi, sā itthī. Bho daṇḍi, bho daṇḍī. Bho sattha, bho satthā. Bho rāja, bho rājā.
Sesato ti kimatthaṃ? Puriso gacchati.
Ga-sī ti kimatthaṃ? Itthiyā; satthussa.

---

Tras los restantes, ‘ga’ y ‘si’ se eliden.

Tras las restantes bases mostradas, ‘ga’ y ‘si’ se eliden.¹

Ejemplos:

* Itthi = itthī + si (‘si’ recibe el nombre ‘ga’ (§57); ‘ī’ recibe el nombre ‘pa’ (§59); ‘ī’ se acorta (§245); ‘ga’ se elide (§220)).
* Itthī = itthī + si (‘si’ se elide (§220)).
* Daṇḍi = daṇḍī + si (‘si’ recibe el nombre ‘ga’ (§57); ‘ī’ recibe el nombre ‘jha’ (§58); ‘ī’ se acorta (§245); ‘ga’ se elide (§220)).
* Daṇḍī = daṇḍī + si (‘si’ se elide (§220)).
* Sattha = satthu + si (‘si’ recibe el nombre ‘ga’ (§57); ‘u’ de “satthu” se convierte en ‘ā’ (§244); ‘ā’ se acorta (§246); ‘ga’ se elide (§220)).
* Satthā = satthu + si (‘u’ de “satthu” se convierte en ‘ā’ (§199); ‘si’ se elide (§199)).
* Rāja = rāja + si (‘si’ recibe el nombre ‘ga’ (§57); ‘a’ se convierte en ‘ā’ (§244); ‘ā’ se acorta (§246); ‘ga’ se elide (§220)).
* Rājā = rāja + si (‘si’ se sustituye por ‘ā’ (§189); ‘a’ se elide (§83)).

¿Cuál es la finalidad de decir “tras los restantes”? [Este sutta no se aplica cuando no hay bases restantes, como en:] Puriso gacchati.

¿Cuál es la finalidad de decir “‘ga’ y ‘si’”? [Este sutta no se aplica cuando no siguen ‘ga’ ni ‘si’, como en:] itthiyā; satthussa.

Nota al pie: Los que están mostrados por los suttas “Si ’ṃ” (§219), “S’ o” (§104), “Sy ā ca” (§189), “Sakhato gass’ e vā” (§113) y “Ghat’ e ca” (§114) se llaman aquí “sesa” [restantes].

Nota del traductor: en los ejemplos, Nandisena imprime “bho daṇḍī”, “bho satthā” y “bho rājā” como segundo miembro de cada par; Pind y Thitzana leen “so daṇḍī”, “so satthā” y “so rājā” (nominativos, en contraste con los vocativos), como su propio primer par “sā itthī”. Un vocativo “bho daṇḍī” con ‘ī’ larga contradiría además §245. Se propone la enmienda bho → so en los tres pares.

**§221. 282. Sabbāsam āvuso-’pasagga-nipātādīhi ca (448).** [Sabbāsaṃ + āvuso-upasagga-nipāta-ādīhi + ca = 3 voces]

Sabbāsaṃ vibhattīnaṃ ekavacanabahuvacanānaṃ paṭhamā-dutiyā-tatiyā-catutthī-pañcamī-chaṭṭhī-sattamīnaṃ lopo hoti āvuso upasagga nipāta icc evamādīhi ca.
Tvaṃ pan’ āvuso; tumhe pan’ āvuso; padaso dhammaṃ vāceyya; vihāraṃ sve upagaccheyya.
Pa, parā, ni, nī, u, du, saṃ, vi, ava, anu, pari, adhi, abhi, pati, su, ā, ati, api, apa, upa.
Pahāro, parābhavo, nihāro, nīhāro, uhāro, duhāro, saṃhāro, vihāro, avahāro, anuhāro, parihāro, adhihāro, abhihāro, patihāro, suhāro, āhāro, athihāro, apihāro, apahāro, upahāro.
Evaṃ vīsati upasaggehi ca, yathā, tathā, evaṃ, khalu, kho, tatra, atho, atha, hi, tu, ca, vā, vo, haṃ, ahaṃ, alaṃ, eva, ho, aho, he, ahe, re, are. Evamādīhi nipātehi ca yojetabbāni.
Caggahaṇam avadhāraṇatthaṃ.

---

Y tras “āvuso”, los prefijos, las partículas, etc., [hay elisión] de todas.

Tras “āvuso”, los prefijos, las partículas, etc., se eliden todas las inflexiones, singulares y plurales, a saber: primera, segunda, tercera, cuarta, quinta, sexta y séptima.

Ejemplos:

* Tvaṃ pan’ āvuso (¿y tú, amigo?); tumhe pan’ āvuso (¿y vosotros, amigos?); padaso dhammaṃ vāceyya (debería hacer recitar el Dhamma palabra por palabra); vihāraṃ sve upagaccheyya (debería acercarse mañana al monasterio).
* Āvuso = āvuso + si (‘si’ se elide (§221)).

Nota: Esta regla se debe emplear tras los veinte prefijos, ‘pa’, etc., y las partículas, ‘yathā’, etc.

Los veinte prefijos son los siguientes: pa, parā, ni, nī, u, du, saṃ, vi, ava, anu, pari, adhi, abhi, pati, su, ā, ati, api, apa, upa. [Ejemplos:] Pahāro, parābhavo, nihāro, nīhāro, uhāro, duhāro, saṃhāro, vihāro, avahāro, anuhāro, parihāro, adhihāro, abhihāro, patihāro, suhāro, āhāro, atihāro, apihāro, apahāro, upahāro. Así con los veinte prefijos; y se deben emplear [igualmente] con las partículas yathā, tathā, evaṃ, khalu, kho, tatra, atho, atha, hi, tu, ca, vā, vo, haṃ, ahaṃ, alaṃ, eva, ho, aho, he, ahe, re, are, etc.

El tomar “ca” es para restringir [el alcance de este sutta].

Nota del traductor: en la lista pāḷi de ejemplos con prefijos Nandisena imprime “athihāro”; su propia lista de prefijos da ‘ati’, y su bloque inglés, Pind y Thitzana leen “atihāro”, por lo que se propone la enmienda athihāro → atihāro. (En la traducción de arriba ya se da la forma corregida; la línea pāḷi conserva la literal.)

**§222. 342. Pumassa liṅgādīsu samāsesu (449).** [Pumassa + liṅga-ādīsu + samāsesu = 3 voces]

Puma icc etassa anto lopam āpajjate liṅgādīsu parapadesu samāsesu.
Pulliṅgaṃ, pumbhāvo, puṅkokilo.
Pumasse ti kimatthaṃ? Itthiliṅgaṃ, napuṃsakaliṅgaṃ.
Liṅgādīsū ti kimatthaṃ? Pumittthī.
Samāsesu ti kimatthaṃ? Pumassa liṅgaṃ.

---

En los compuestos de “puma”, cuando [la palabra] “liṅga”, etc.

En los compuestos, cuando [las palabras] “liṅga”, etc., son el miembro siguiente, la [vocal] final de “puma” se elide.¹

Ejemplos:

* Pulliṅgaṃ = puma + liṅgaṃ (‘a’ de “puma” se elide (§222); ‘m’ se sustituye por ‘ṃ’ (§82); ‘ṃ’ se sustituye por ‘l’ (“vā” en §31)).
* Pumbhāvo = puma + bhāvo (‘a’ de “puma” se elide (§222); ‘m’ se sustituye por ‘ṃ’ (§82); ‘ṃ’ se sustituye por ‘m’ (§31)).
* Puṅkokilo = puma + kokilo (‘a’ de “puma” se elide (§222); ‘m’ se sustituye por ‘ṃ’ (§82); ‘ṃ’ se sustituye por ‘ṅ’ (§31)).

¿Cuál es la finalidad de decir “de ‘puma’”? [Este sutta no se aplica cuando no hay “puma”, como en:] itthiliṅgaṃ, napuṃsakaliṅgaṃ.

¿Cuál es la finalidad de decir “cuando ‘liṅga’, etc., [son el miembro siguiente]”? [Este sutta no se aplica cuando “liṅga”, etc., no son el miembro siguiente, como en:] Pumitthī.

¿Cuál es la finalidad de decir “en los compuestos”? [Este sutta no se aplica cuando no hay compuestos, como en:] Pumassa liṅgaṃ.

Nota al pie: Parapadesu pi.

Nota del traductor: en la tercera pregunta kimatthaṃ Nandisena imprime “Pumittthī”, con tres tes; la respuesta a la segunda pregunta y Pind leen “Pumitthī” (por cotejar con el PDF, posible errata del OCR).

**§225. 151. Yonaṃ no (452).** [Yonaṃ + no = 2 voces]

Sabessaṃ yonaṃ jhato katarassā no hoti.
Daṇḍino bhogino; he daṇḍino, he bhogino.

¿Cuál es la finalidad de decir “tras ‘jha’”? [Este sutta no se aplica cuando no hay ‘jha’, como en:] Sayambhuno.

¿Cuál es la finalidad de decir “de ‘yo’”? [Este sutta no se aplica cuando no hay ‘yo’, como en:] daṇḍinā, bhoginā.

* Vadhu = vadhū + si (‘si’ recibe el nombre ‘ga’ (§57); ‘ū’ recibe el nombre ‘pa’ (§59); ‘ū’ se acorta (§245); ‘si’ se elide (§220)).

**§246. 73. Ākāro vā (476, 478-9).** [Ākāro + vā = 2 voces]

Ākāro rassam āpajjate vā ge pare.
Bho rāja, bho rājā; bho atta, bho attā; bho sakha, bho sakhā; bho sattha, bho satthā.

---

Opcionalmente, la letra ‘ā’.

Opcionalmente, cuando sigue ‘ga’, ‘ā’ se acorta.

Ejemplos:

* Rāja = rāja + si (‘si’ recibe el nombre ‘ga’ (§57); ‘a’ se convierte en ‘ā’ (§244); ‘ā’ se acorta (§246); ‘si’ se elide (§220)).
* Rājā = rāja + si (‘si’ recibe el nombre ‘ga’ (§57); ‘a’ se convierte en ‘ā’ (§244); ‘si’ se elide (§220)).
* Atta = atta + si (‘si’ recibe el nombre ‘ga’ (§57); ‘a’ se convierte en ‘ā’ (§244); ‘ā’ se acorta (§246); ‘si’ se elide (§220)).
* Attā = atta + si (‘si’ recibe el nombre ‘ga’ (§57); ‘a’ se convierte en ‘ā’ (§244); ‘si’ se elide (§220)).
* Sakha = sakha + si (‘si’ recibe el nombre ‘ga’ (§57); ‘a’ se convierte en ‘ā’ (§244); ‘ā’ se acorta (§246); ‘si’ se elide (§220)).
* Sakhā = sakha + si (‘si’ recibe el nombre ‘ga’ (§57); ‘a’ se convierte en ‘ā’ (§244); ‘si’ se elide (§220)).
* Sattha = satthu + si (‘si’ recibe el nombre ‘ga’ (§57); ‘u’ de “satthu” se convierte en ‘ā’ (§244); ‘ā’ se acorta (§246); ‘si’ se elide (§220)).
* Satthā = satthu + si (‘si’ recibe el nombre ‘ga’ (§57); ‘u’ de “satthu” se convierte en ‘ā’ (§244); ‘si’ se elide (§220)).

Nota del traductor: en el desglose Nandisena escribe “by this sutta ‘a’ is shortened”; lo que se acorta es la ‘ā’ producida por §244 (su propia glosa y vutti dicen “‘ā’ becomes short”), por lo que se propone la enmienda ‘a’ → ‘ā’.

**Así termina la cuarta sección del capítulo de Nāma.**
